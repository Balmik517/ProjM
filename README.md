ProjM - Legacy Monolith Application
A robust Java-based backend application built using the Spring Framework, designed as a traditional monolithic architecture. This project serves as a comprehensive example of integrating Spring Boot and Spring MVC with server-side rendering.

🚀 Overview
This project is a legacy-style web application that utilizes JSP (JavaServer Pages) for the frontend, providing a seamless server-side transition between the backend logic and the user interface. It is configured as a monolith to manage all business logic, data access, and view rendering within a single deployable unit.

🛠 Tech Stack
Language: Java

Framework: Spring Boot (with Spring MVC)

View Engine: JSP (JavaServer Pages)

Build Tool: Maven

Architecture: Monolithic

📋 Features
Spring MVC Architecture: Clear separation of concerns using Models, Views, and Controllers.

Server-Side Rendering: Dynamic content generation via JSP.

Spring Boot Integration: Simplified configuration and embedded server deployment.

Legacy Integration: Designed to demonstrate or maintain traditional enterprise patterns.

⚙️ Prerequisites
JDK: 1.8 or higher

Maven: 3.6+

IDE: IntelliJ IDEA, Eclipse, or VS Code

🏃 Getting Started
Clone the repository:

Bash
git clone https://github.com/Balmik517/ProjM.git
Build the project:

Bash
mvn clean install
Run the application:

Bash
mvn spring-boot:run
Access the App:
Open your browser and navigate to http://localhost:8080.
